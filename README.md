# A-Share Financial Fraud Risk Skill

A modular LLM skill that turns financial statements into fraud risk analysis for Chinese A-share companies.

> 🚧 Work in progress

## Planned Modules

1. **Data collection** — fetch financial statements via public APIs
2. **Ratio screening** — Beneish M-Score, accrual quality, cash flow vs. earnings divergence
3. **LLM interpretation** — generate a structured red-flag report
4. **Evaluation** — backtest on known fraud cases vs. normal peers
